## 一、四台机器

英文名：`Geo-Pulse Energy Conversion Hub`

**说明（3 行）：**
```
线圈可以混搭：以结构里数量占比最多的线圈作为温度判定基准，为三个模块提供能量，
同时根据线圈温度提供电量减免——5400K 起算，每提升 240K 提升 1% 减免，最高 50%。
枢纽最多可为 12 个模块提供能量。
结构来源：BV1RgXTBVEJ1
```

## 二、说明里的数字会不会自己变

| 机器 | 数字 | 来源 | 改了之后说明自动更新？ |
|---|---|---|---|
| 枢纽 | 5400K / 240K / 1% / 50% / 12 台 | 语言文件（静态文案） | 否（需要改文案） |
| 呼吸加热单元 | `耗时倍率 0.1` | 配置 `coilDiscount.durationMultiplier` | **是** |
| 呼吸加热单元 | `+100K` | 代码常量 `TEMPERATURE_PER_VOLTAGE_TIER` | 是（改常量重编译） |
| 呼吸加热单元 | `83 mB` | 配置 `dualFluidTax.ivBaselineMbPerSecond` | **是** |
| 呼吸加热单元 | `×4` | 配置 `dualFluidTax.perTierMultiplier` | **是** |
| 呼吸加热单元 | `岩浆 / 液态烈焰` | 配置的流体 id 指向的流体本地化名 | **是** |
| 黑奴挖矿机 | `耗能倍数 6` | 配置 `stripper.energyMultiplier`（默认 6） | **是** |
| 黑奴挖矿机 | 主机名 / 128·64·32·16 / 公式 | 代码常量 `EMBEDDABLE_MAINFRAMES`、`MAX_BOOST_COUNT`、`PARALLEL_BOOST_*` | 是（改常量重编译） |

> 动态说明实现：`MachineDefinition#setTooltipBuilder`（每次渲染 tooltip 时现算）。
> 对应 `MoltenBlastModuleMachine.appendConfiguredTooltips` / `MoltenStripperModuleMachine.appendConfiguredTooltips`。

## 三、机制总表（代码口径）

### 地心涌动能量转换枢纽
| 项目 | 内容 |
|---|---|
| 成形结构 | 整栋「地心涌动能量转换站」大楼 97×48×99（三个模块区域已挖空，成形不依赖模块） |
| 线圈判定格 | 本楼 **1773 格**，自研判定 `modularHeatingCoils()`：**允许混搭**，不要求整楼同一种 |
| 温度基准 | **格子数最多**的线圈（并列取更热）；**实时读取**，换线圈立即生效、不必重判结构 |
| 电量减免 | `min(50%, (热容 − 5400) ÷ 240 × 1%)`：5400K 以下 0%，**17400K 起封顶 50%** |
| 中央供电 | 模块无能源仓，逐 tick 向枢纽取电；枢纽界面显示 `模块实付: X EU/t（近 1 秒实际扣电）` |
| 模块上限 | **12 台**（半径 96 / 垂直 64 扫描） |
| 界面 | `加热线圈: 名字 · <T> K · 线圈格 1773 · 模块能耗 -N%`；混放时多一行「线圈格构成」 |

### 猪咪愤怒烧矿机
| 项目 | 内容 |
|---|---|
| 配方表 | `gtceu:electric_blast_furnace`（BLAST） |
| 有效炉温 | `枢纽热容 + 100 × max(0, 电压等级 − MV)`；界面显示 `热容: <K>`、`判定炉温: <K>` |
| 温度判定 | 有效炉温 ≥ 配方 `ebf_temp` 才运行，否则提示「温度不足」 |
| 耗时倍率 | 配置 `coilDiscount.durationMultiplier`（默认 0.1） |
| 线圈降耗 | EU/t × `clamp(0.95^(线圈档−1), 0.5~1)`（配置项） |
| 运行税 | 每秒各扣 83 mB 岩浆与液态烈焰（IV 基准，每高一档 ×4；低于 IV 不运行） |
| 供电 | 自身无能源仓 / 维护仓 / 消声仓，全部由枢纽供给 |

### 猪咪黑奴挖矿机
| 项目 | 内容 |
|---|---|
| 配方表 | `gtceu:star_core_stripper` |
| 跨配方并行 | 一次执行**所有匹配配方**，每条配方并行数**相同** = `1536 + max(0, 枢纽热容 − 21600) / 1200 × 300` |
| 处理器主机 | 右键（含潜行）嵌入：寰宇 128 / 奇异 64 / 光学 32 / 生物活性 16，总量封顶 128；倍率 `2^(6 + 10×((n−1)/184)²)`；拆机掉落归还 |
| 耗能 / 耗时倍数 | 配置 `stripper.energyMultiplier`（默认 **6**）/ `stripper.durationMultiplier`（默认 1） |
| 结构限制 | **不允许安装并行控制仓** |
| 界面 | `同时处理至多 N 个配方` + 彩虹「无限个跨配方线程」+ `已安装 x/128 个处理器主机` |

### 猪咪撕咬炼矿机
| 项目 | 内容 |
|---|---|
| 配方表 | `gtceu:space_ore_processor`（不消耗星能火箭燃料） |
| 并行 | 由并行控制仓提供 |
| **隐性联动** | 枢纽热容 **≥ 16200K** → 并行拉满 `2147483647`（并行仓失效）；界面不写说明，只把并行行数字换成彩虹特效 |
| 跨配方线程 | 64 |
| 界面 | 并行行 + 线程行；不显示热容 / 判定炉温行 |
| 运行税 | 继承呼吸加热单元（岩浆 + 液态烈焰双流体） |

### 三模块共有
- 自身**不带**能源仓 / 维护仓 / 消声仓，也没有独立线圈：温度与供电全来自枢纽；
- 枢纽未成形或未连接 → 配方逻辑等待「主机不可用」，来电后自动恢复；
- 换线圈 / 重建枢纽 / 重组模块后数值自动重算，不需要拆结构。
