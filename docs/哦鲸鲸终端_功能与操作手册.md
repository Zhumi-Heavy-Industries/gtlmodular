# 哦鲸鲸终端 · 功能与操作手册

> 对应版本：`0.3.155` ｜ 物品 id：`gtlmodular:whale_terminal`
> 基于 GT-Shanhai「山海终极终端」完整移植 + eco 风格 UI + 远程子系统（含距离绕过）

---

## 0. 一句话

**一个拿在手里的多方块施工终端**：扫描/施工/拆解 GTCEu 多方块，自动从背包或 AE 网络取料，
可自动下 AE 合成单；同时能绑定 eco 计算通讯接口，远程打开计算子系统主机 UI。

---

## 1. 获取方式

- 创造标签页：**更多实用设备-工具**
- 工作台无序合成：
  `gtlcore:ultimate_terminal` ×1 + `gtceu:bronze_ingot` ×2 + `gtceu:steel_ingot` ×1
- 物品不可堆叠（`stacksTo(1)`），所有设置都保存在物品 NBT 里

---

## 2. 操作总表

| 操作 | 作用 |
|---|---|
| **右键 GT 多方块控制器** | 只扫描：聊天摘要 + 世界内方块高亮 + 完整报告链接 |
| **右键其它方块 / 空气** | 打开「哦鲸鲸终端」设置屏 |
| **左键（已绑定计算通讯接口）** | 打开绑定的 **计算子系统主机** UI（优先于扫描） |
| **左键 GT 多方块控制器** | 同右键：只扫描 |
| **潜行右击 GT 多方块控制器** | 扫描 → 备料 → 施工；拆解模式则拆解 |
| **潜行右击 AE 网络节点** | 绑定 AE 网络（取料 / 回收 / 自动下单） |
| **潜行右击「计算通讯接口」** | 绑定计算子系统（远程打开的主机锚点） |
| **点击聊天里的「[点击查看…报告]」** | 打开完整报告屏 |
| 设置屏右上角「远程打开」 | 打开已绑定的计算子系统主机 UI |
| 设置屏「打开子系统」（未绑定时） | 扫描附近 32 格内最近的已成型计算子系统并打开 |

> 注意：普通右键不再扫描/施工，统一进设置屏；扫描/施工/绑定都要**按住潜行**。

## 3. 设置屏：8 个开关

面板中段「控制开关」4×2 的竖直拨杆，蓝色 = 开，灰色 = 关。

### 3.1 镜像模式（Mirror）
- 开：按结构的**镜像变体**扫描与施工
- 关：按正常朝向
- 用途：同一台多方块有左右/前后镜像版本时，不用手动摆镜像

### 3.2 功能部件替换（Replace）
- 开：启用**等级方块替换**（同家族但等级不对的方块 → 判为替换）
- 关：等级方块只要“是同一类”就算满足，不替换
- 需要先在下面「功能部件等级」里选好目标等级，否则没有可替换项

### 3.3 绝对替换模式（Absolute Replace）
- 开：施工时**强制拆除**结构位置上不合法的挡路方块并重放
- 关：只把它们报成“阻塞”，不动手
- 建议只在确认多余方块可以拆时开

### 3.4 AE 模式（AE Mode）
- 开：施工/拆解优先从**绑定的 AE 网络**取料、把拆解物回收到 AE
- 关：只用玩家背包
- 必须先用「潜行右击 AE 节点」绑定，否则按未绑定处理（聊天会提示）

### 3.5 下单功能（Order）
- 默认开；仅 AE 模式 + 已绑定 AE 时生效
- 开：材料有缺口时，自动让 AE 计算合成方案并提交下单
- 关：只报告缺口，不下单
- 下单后通常需要**再次潜行右击控制器**确认施工（见 §7）

### 3.6 无仓室模式（No Chamber）
- **默认开**
- 关：仓室位置**只高亮提示**，不放置任何方块
- 开：仓室位置用**普通候选方块占位**（之后自己换成真正的仓室）
- 仓室类型：输入/输出/能源/维护/并行/消声/数据/其他

### 3.7 拆解模式（Dismantle）
- 开：潜行右击控制器 = **按结构拆回材料**，而不是施工
- 有 AE 网络：拆解物直接进 AE
- 没 AE：拆解物进玩家背包；**背包放不下会拒绝拆解**（避免吞物品）
- 拆解出的**流体必须走 AE**（没有 AE 时不支持流体回收）

### 3.8 模块检查（Module Check）
- 开：左键控制器的扫描不再出施工计划，改为**高亮结构里机器模块的可插槽位置**（仅主机）
- 关：左键扫描输出正常施工报告

## 4. 重复层数（0 ~ 648）

- 适用于**层数可变**的多方块（塔式反应器、可叠层结构等）
- 0 = 只按结构定义的最小/固定层数
- 数字 = 额外重复的层数（不是总层数）
- 固定层结构不受影响

---

## 5. 功能部件等级（等级方块选择）

点设置屏「选择功能部件等级」那一行 → 打开**方块图标选择子界面**：

- 每一行一个家族，行内直接铺出**每一档方块的本体图标**
- 中文家族名（与 gtlcore 终极终端一致）：
  - `SC` → **恒星热力容器**
  - `SEPM` → **太空电梯模块**
  - `CAL` → **部件装配外壳**
  - `COIL` → **线圈**
- 鼠标悬停：显示方块名 + `(当前档/总档)`
- 点击图标：立即选中并返回设置屏
- 设置屏的等级行会显示：`选择功能部件等级：<选中的方块名>` + 方块图标 + 「选择 ▸」

> 只有开启「功能部件替换」后，选中的等级才会在施工时生效。

## 6. 两种绑定

### 6.1 绑定 AE 网络
- **潜行右击**任意 AE 网络节点（线缆/机器/接口等有网络的方块）
- 成功：`[哦鲸鲸终端] 已绑定 AE 网络节点 <坐标>`
- 用途：AE 模式下取料、回收拆解物、自动下单
- 物品 tooltip / 设置屏底部显示「AE 网络：已绑定/未绑定」

### 6.2 绑定计算通讯接口（eco）
- **潜行右击** eco 的「计算通讯接口」
- 成功：`[哦鲸鲸终端] 已绑定计算通讯接口 <坐标>`
- 它只是**锚点**；打开时终端会从接口找到它所属的**计算集群主机**，弹的是**主机 UI**，不是接口自己的 UI
- 设置屏底部显示「计算通讯接口：已绑定/未绑定」

## 7. 扫描 / 施工 / 拆解流程

### 7.1 只扫描
- **左键** GT 多方块控制器
- 输出：聊天摘要（缺失/替换/阻塞/手动/可放仓室）+ 世界内方块高亮 15 秒 + 完整报告链接
- 开「模块检查」时改为输出模块插槽位置高亮

### 7.2 施工（创造模式）
- **潜行右击**控制器 → 直接按计划施工，不消耗材料（但仍检查建造高度）

### 7.3 施工（生存模式）
- **第一次潜行右击**：扫描 + 备料
  - 材料齐全 / 无替换 → 直接施工
  - 有替换计划 → 提示「替换计划已准备；再次潜行右击确认施工」
  - AE 下单模式且有缺口 → 自动算/提交合成，提示再次潜行右击施工
- **第二次潜行右击**：确认并执行施工（缺料位置跳过，施工报告列出）

### 7.4 拆解
- 开「拆解模式」后**潜行右击**控制器
- 按结构逐块拆回材料，输出「回收 N 处」+ 施工报告
- 无 AE 时要求背包能完整放下，否则拒绝

### 7.5 建造高度校验
- 施工前检查世界高度 + GTCEu 多方块 Y 上限
- 越界会拒绝并提示第一个越界坐标

## 8. 报告屏（完整报告）

聊天里只放摘要；点「[点击查看详细报告]」进入完整报告屏：

| 功能 | 说明 |
|---|---|
| 分类筛选 | 底部按钮循环切换：全部 → 缺失 → 替换 → 阻塞 → 手动 → 可放仓室 … |
| 滚动 | 滚轮滚动列表，右侧金色滚动条 |
| 点击某行 | 复制该方块坐标，左下角提示 |
| 「复制全部坐标」 | 复制当前筛选下全部坐标（每行一个） |
| 「显示坐标方框」 | 在世界里把当前筛选的坐标标成方框（30 秒） |
| 报告类型 | 结构扫描 / 施工明细 / 合成下单 / 模块位置 |
| 保留数量 | 客户端最多保留最近 8 份报告 |

> 高亮依赖 Glodium；没装时只保留聊天里的坐标标识。

## 9. 远程计算子系统 UI

### 用法
1. 潜行右击「计算通讯接口」绑定
2. 走远（≥ 8 格也可以）
3. **左键**（或设置屏「远程打开」）
4. 弹出 **计算子系统主机** UI

### 实现说明（重要）
- eco 原生 UI 有两道硬编码 8 格检查：
  1. `BlockUIHolder.isInvalid()` 里的 `stillValid`
  2. 主机 `ECOComputationSystem.createUI()` 里又检查一次 `isPlayerCloseEnough`
- 终端通过两个**软依赖 Mixin** 在“玩家持有本终端”时放行这两道检查
- 打开前服务端会加载接口周围 5×5 区块、并把**主机所在区块**补发给客户端，保证客户端能构建 UI
- 同一维度有效；跨维度会提示先到同一维度

### 风险
- Mixin 直接改 eco 的类，**eco 更新后可能失效**
- 跨区块补发数据偶尔会有客户端区块闪烁/卡顿
- 若失败，服务端日志会写 `[哦鲸鲸终端] 远程打开失败：…`，按那条日志定位

## 10. 已知限制

1. **没有虚拟盘（SDA）集成**：拆解无 AE 时只能进背包，背包满会拒绝；流体回收必须 AE。
2. **拆解出的流体**没有容器可给，必须绑 AE。
3. **远程子系统仅同维度**，不支持跨维度。
4. 距离绕过依赖 Mixin，属于 hack 方案；升级 eco 前先备份存档。
5. 终端本身不可堆叠；复制物品会复制 NBT（包括绑定和设置）。

## 11. 常见问题

| 现象 | 原因/处理 |
|---|---|
| 右键机器没扫描/施工 | 现在普通右键是开设置；请**潜行右击**控制器 |
| 左键点方块变成挖方块 | 只有已绑定计算接口时左键才拦截；未绑定则正常挖掘 |
| 「请先普通右击…」 | 旧版本提示；0.3.155 起第一次潜行右击会自动准备计划 |
| AE 模式提示未绑定 | 潜行右击一个 AE 网络节点 |
| 远程打开提示“不可用” | 看日志 `[哦鲸鲸终端] 远程打开失败：…`：接口 BE 未加载 / 集群无主机 / openUI false |
| 报告链接点了没反应 | 报告已过期（客户端只保留 8 份/15 秒聊天链接），重新扫描 |
| 拆解不动 | 背包放不下且没有 AE；或拆解模式没开 |
| 替换不生效 | 「功能部件替换」没开，或没选目标等级，或选中的家族不对 |
