# 依赖

编译和运行都用 **JDK 21**。本模组输出 Java 17 字节码，但 NAC 继承的 GTL Additions 基类是 Java 21 字节码，所以不能用 Java 17 启动整合包。

开发环境：Minecraft 1.20.1、Forge 47.4.16、Gradle Wrapper 8.5。Minecraft 和 Forge 由 Gradle 自动下载；模组依赖要手动放进 `libs/`。

`libs/runtime/` 放只在运行时需要的 jar（目前是 `GTL-Enhancedcore-3.3.3.jar`）。它们不参与编译，只给 `decompileDeps` 反编译查源码用，以及给完整版 GameTest 加载。`libs/` 下的其他子目录不参与编译。

两个 jar 都不内嵌依赖。玩家安装时：

- 独立版 `gtl_nac` 必需：Forge ≥47.3.7、GTCEu ≥1.4.4、LDLib ≥1.0.33.b、AE2 ≥15、gtlcore ≥1.2.3.2-fix4、gtladditions ≥3.3.1Custom（普通版或亚空间版都行）、gtmthings ≥1.3.5；客户端另需 Cloth Config ≥11。Jade、JEI 可选。
- 完整版 `gtlmodular`：按整合包实际环境配齐，至少包括上面这些。

## 测试依赖（`libs/testrun/`）

两套 GameTest 需要的 jar 放在 `libs/testrun/`（不进 git）。两种准备方式：

1. **直接解压**：向另一位开发者要 `gtlmodular-测试依赖.zip`，解压到 `libs/testrun/`。里面有整合包的定制版 jar，所以不放进公开仓库。
2. **用脚本下载**（需要 Python 3.10+，Windows 用 `py -3` 代替 `python3`）：
   ```sh
   python3 scripts/download-test-deps.py --reuse-only   # 只从 libs/ 复制已有的，不联网
   python3 scripts/download-test-deps.py                # 复制已有的，缺的从官方地址下载
   python3 scripts/download-test-deps.py --check        # 只检查，不改任何文件
   ```
   整合包定制版（gtlcore、gtladditions、gtmthings、Enhancedcore）没有公网地址，脚本只能从 `libs/` 复制。
